# Sicher unterwegs – HTML-Nachbau des Rise-Storyboards

`index.html` bildet das Storyboard „Sicher unterwegs – Dienstfahrten, Ergonomie, Ladungssicherung“ als eigenständige Schulungseinheit im Stil von Articulate Rise nach (eine Datei, ohne Abhängigkeiten; einfach im Browser öffnen).

- 6 Pflichtlektionen + freiwillige Vertiefung, lineare Navigation (nächste Lektion erst nach Abschluss der vorherigen)
- Farben Anthrazit `#1B2A33`, Orange `#F5A200`, Warnrot `#C93C3C`; Schrift Calibri (Fallback Carlito)
- Rise-Blöcke nachgebaut: Statement, Note, Zitat, Flashcards, Tabs, Akkordeon, Checkliste, Prozess, Wissensfrage, Szenario, beschriftete Grafik, Sortieraufgabe, Quiz (8 Fragen, bestanden ab 6, Wiederholung), YouTube-Video mit Kapitelsprüngen
- Fotos sind als gestrichelte Platzhalter mit Bildbeschreibung bzw. Alt-Text angelegt; `[Platzhalter]` aus dem Storyboard sind gelb markiert
- Fortschritt wird im Browser (localStorage) gespeichert; eine LMS-/SCORM-Anbindung ist nicht enthalten (Stelle im Code markiert)
